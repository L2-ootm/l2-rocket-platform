## Physics invariant

OpenRocket `<appearance>` is cosmetic. OpenRocket `<finish>` changes drag.
Every livery build must:

1. retain exactly three `<finish>normal</finish>` tags;
2. match unliveried Candidate K telemetry exactly;
3. retain one stored simulation and two flight branches;
4. resolve every declared `decals/...` entry after packaging;
5. continue all heightfield and mission-datum crossings across the stage seam.
